# cleanrules

An explainable rules engine with one Rust core and the same semantics in Rust,
C/C++, Python, JavaScript, Java/Scala, Go and Erlang: business rules, expert systems,
data validation and explaining ML models, with crisp (three-valued Kleene) and
fuzzy logic. Every result explains itself.

> **Pre-alpha.** The core is being built against the specification and the
> conformance vectors in <https://github.com/cleanrules/cleanrules>.
